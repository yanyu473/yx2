# 坦克大战 · 星际守护者

> 深空防线 · 霓虹机甲 · 守护星河
> 一个纯前端、零依赖、自包含的科幻风俯视角坦克射击网页游戏。

全部图形用 Canvas 矢量绘制，全部音效/BGM 用 Web Audio API 程序化合成——**不依赖任何外部图片或音频文件**，单文件 HTML 双击即可运行，可直接发微信。

---

## 两种运行方式

### 方式一：单文件版（推荐 · 开箱即玩）
双击 `坦克大战-星际守护者.html`，或拖进任意浏览器即可。
> 该文件内联了全部 CSS / JS / Canvas 绘图 / Web Audio 合成音，体积约 143KB，可直接发给朋友/发微信，对方双击即玩。

### 方式二：项目源码版（阅读/二次开发）
用浏览器打开 `index.html`。由于浏览器安全策略，建议用本地服务器打开：

```bash
# 进入项目目录
cd "D:\坦克大战-星际守护者"

# 任选其一启动本地服务器：
python -m http.server 8000      # Python3
npx serve .                     # Node.js (需先 npm i -g serve)
# 然后浏览器访问 http://localhost:8000
```

> 重新打包单文件：`node build-single.js`（会读取 css/ + js/ 并生成 `坦克大战-星际守护者.html`）

## 操作说明

### 键位（桌面）

#### 玩家1（单人模式默认）
| 按键 | 功能 |
| ---- | ---- |
| `W A S D` | 移动战车 |
| 鼠标移动 | 炮塔瞄准（鼠标方向） |
| 鼠标左键 / `空格` | 手动射击 |
| `F` | 切换自动射击开/关 |
| `Q` | **护盾技能**（短暂无敌，吸收敌弹） |
| `E` | **全屏清屏技能**（清空敌弹 + 对全场敌人造成伤害） |
| `R` | **投降**（二次确认后结束本局并结算） |
| `P` / `Esc` | 暂停 / 继续 |

#### 玩家2（双人模式）
| 按键 | 功能 |
| ---- | ---- |
| `↑ ↓ ← →` | 移动战车 |
| `/`（斜杠键）或 `Numpad0` | 手动射击 |
| `.`（句号） | 护盾技能 |
| `,`（逗号） | 全屏清屏技能 |
| `右Ctrl` | 投降 |

> 不移动鼠标时炮塔会自动锁定最近敌人；P2 始终自动瞄准最近敌人；自动射击默认开启。

### 触屏（移动端，可选）
- 左半屏拖拽：战车朝拖拽方向移动
- 右半屏点按：瞄准 + 射击

### 玩法循环
1. 主菜单 → 选择战车（4 种，属性各异，**双击确认**）→ 选择游戏模式（单人/双人合作/双人对决）→ 选择战线难度（4 档）→ 出击
2. 击杀敌人累计分数与连击；掉落道具拾取强化
3. 紧张度随分数/波次上升：敌人变多变快、弹幕变密、BGM 转紧张
4. 第 5 波（或破 9000 分）触发 **Boss 深渊执政官** 出场 CG，多阶段弹幕
5. 击败 Boss → 胜利结算 CG；血量归零 → 失败结算 CG
6. 双人 PK 模式：两名玩家互相对抗，击杀对方获分，最终比积分高低定胜负

## 已实现功能清单

- **A 技能系统**：护盾(Q/.), 全屏清屏(E/,), 投降(R/右Ctrl)，均有 HUD 冷却倒计时
- **B 完整界面流程**：加载动画 → 主菜单（标题动画）→ 角色选择（卡片+动效，**双击确认**）→ **模式选择**（单人/合作/PK）→ 难度选择 → 战斗 HUD → 暂停菜单 → 结算画面 → 勋章展馆，界面间 CSS 过渡
- **C CG 动画**：Boss 出场全屏特写（闪光+扫描线+名字推进）、胜利/失败结算 CG
- **D 拟人化敌人**：敌人随机弹出嘲讽气泡（就这？/受死吧！/别追我！等），多性格台词池，气泡淡入淡出
- **E 对局节奏**：基于分数的"紧张度"参数，影响敌人数量/速度/弹幕密度/BGM
- **F 多阶段 BGM**：主菜单/轻松战斗/紧张战斗(叠加紧张层)/Boss战/胜利/失败，Web Audio 程序化合成，平滑切换
- **G 战斗特效**：枪口闪光、子弹拖尾、命中粒子飞溅、敌人粒子爆炸、受击红屏+震屏、拾取光环、Boss 大爆炸连击+强震屏+慢动作、全程 screen shake
- **H 成就勋章系统**：15 个成就，**勋章展馆时间轴展示**（按获得时间排列，每个勋章显示精确获得时间），未解锁勋章灰色锁定显示，记录获得时间(年月日时分)存 localStorage，解锁实时弹窗
- **I 核心机制**：WASD/鼠标移动+自动瞄准、波次系统、普通(多移动模式)/精英(追踪)/Boss(3阶段状态机)、道具系统、圆碰撞检测+穿透处理、对象池(子弹/敌人/粒子/道具)复用、固定步长(1/60s)游戏循环、移动端触摸、localStorage 存最高分/成就
- **J 双人模式**：单人/双人合作(同阵营对抗AI)/双人对决PK(互相攻击比积分)，P1(WASD+Q/E/R)和P2(方向键+./,/右Ctrl)独立键位，双人HUD同时显示双方HP/分数/技能冷却
- **K 游戏简介/教程界面**：主菜单新增"游戏简介"入口，展示移动/射击/技能/暂停/目标/双人键位总览，科幻风格排版

## 技术栈
纯 HTML5 + CSS3 + 原生 JavaScript（无框架/无构建依赖）+ Canvas 2D + Web Audio API + localStorage。
全局命名空间 `TG`，模块用 IIFE 挂载，普通 `<script>` 顺序加载（非 ES Module），因此 `file://` 双击也能跑。

## 自由发挥的加分项
- **紧张度可视化 HUD**：顶部紧张度进度条（绿→金→品红）实时反映战况
- **连击系统**：连续击杀提升分数倍率，连击数 HUD 弹出
- **自动瞄准**：不操作鼠标时炮塔自动锁定最近敌人，降低上手门槛
- **角色卡片实时机甲预览**：选择界面每张卡片的机甲持续旋转动效
- **难度缩略图动态预览**：关卡卡片各自带星空+机甲动画
- **Boss 阶段切换提示** + 召唤小怪
- **慢动作结算**：击败 Boss 触发 timeScale 慢动作 + 连环爆炸
- **护盾吸收敌弹**：护盾开启时吸收接触的敌弹并爆出粒子
- **BGM 紧张层叠加**：同一曲目在紧张阶段叠加 hi-hat 噪声与高音脉冲
- **build-single.js 一键打包**：改完模块跑一下即同步生成单文件
